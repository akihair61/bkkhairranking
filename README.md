バンコク日系ヘアサロン特集 2026（Wix から 2026-10-27 に移行。GitHub Pages で配信・0円）。

- 編集するもの: `gen.mjs`（4言語の文章・リンク・CSS）と `src/`（画像・ブログ本文 JSON）
- 書き出し: `node gen.mjs` → `docs/` が全ページ。`docs/` をコミットして push すれば公開される
- 独自ドメイン: `docs/CNAME`（www.bkkhairrangking.com）。DNS は Wix（レジストラ）側で GitHub Pages へ向ける
- 予約ボタン: Ciel は ciel-hair-studio.web.app/booking（Fresha は廃止済み）
